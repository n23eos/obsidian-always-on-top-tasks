# План: правки по автоматическому ревью каталога (релиз 0.5.0)

## Что показал отчёт по 0.4.0

Пройдено: сеть, поведение, зависимости, обфускация.

Сотни варнингов `@typescript-eslint/no-unsafe-*` — **ложные**. Проверено
локально: тот же набор правил с разрешёнными типами даёт **3 ошибки вместо
~500**. Признак в самом отчёте: строки `main.ts:67`, `FocusOverlayView.ts:51`,
`OverlayController.ts:20` — это `TFile | null` и `WorkspaceLeaf | null`, то есть
типы из пакета `obsidian`. У линтера ревьюера он не разрешился, потому что
плагин лежит в подпапке `obsidian-plugin/`, а не в корне репозитория.

Настоящих замечаний три: аттестации артефактов, декларативные настройки и три
ошибки линтера.

## Шаг 1. Плагин переезжает в корень репозитория

В корень: `package.json`, `package-lock.json`, `tsconfig.json`,
`esbuild.config.mjs`, `eslint.config.mjs`, `styles.css`, `src/`, `tests/`,
`scripts/`, `.env`. Корневой `manifest.json` остаётся единственным — дубль
исчезает вместе с риском рассинхрона.

Swift-приложение уезжает в `macos/`: `Package.swift`, `Sources/`, `Tests/`,
`build_app.sh`.

Правим за переездом: `scripts/install-local.mjs`, `scripts/bump-version.mjs`
(теперь один манифест), `.github/workflows/release.yml` (убрать
`working-directory` и проверку совпадения двух манифестов), `README.md`,
`docs/publishing.md`, `docs/screenshots/render.mjs` (путь к `styles.css`),
`docs/simplefocus.md`, `.gitignore`. `obsidian-plugin/README.md` удаляется.

**Симлинк в vault.** Сейчас в Raincoat симлинк на `obsidian-plugin/`. После
переезда корень плагина = корень репозитория, и симлинк потащил бы в vault
`.git`, `macos/`, `docs/`. Поэтому `install-local` меняем: создаёт в vault
настоящую папку и симлинкует в неё три файла — `main.js`, `manifest.json`,
`styles.css`. Живая пересборка сохраняется, мусор в vault не попадает.

verify: из корня `npm test`, `npx tsc --noEmit`, `npm run build`;
из `macos/` — `swift build` и `swift test`; `npm run install-local` даёт в
vault папку из трёх симлинков; плагин в Obsidian грузится.

## Шаг 2. ESLint как ворота

`eslint.config.mjs` на `typescript-eslint` `recommendedTypeChecked` — ровно то,
чем ревьюер проверяет код. `npm run lint` в scripts, шаг в `release.yml` перед
сборкой.

verify: `npm run lint` без ошибок; заведомая ошибка роняет CI.

## Шаг 3. Три реальные ошибки линтера

1. `main.ts:74` — `loadData()` возвращает `any`, результат расплывается в
   настройки. Типизировать явно.
2. `FocusOverlayView.ts:105` — `onOpen` объявлен `async`, но `await` внутри нет.
3. `FocusOverlayView.ts:140` — то же у `onClose`.

verify: `npm run lint` чисто, `npm test` зелёный.

## Шаг 4. Аттестации артефактов релиза

Рекомендация из отчёта: `main.js` и `styles.css` без provenance. Добавляем в
`release.yml` шаг `actions/attest-build-provenance` и права `id-token: write`,
`attestations: write` рядом с существующим `contents: write`.

verify: у релиза 0.5.0 на GitHub появляется отметка об аттестации;
`gh attestation verify main.js --repo n23eos/obsidian-always-on-top-tasks`
проходит.

## Шаг 5. Декларативные настройки, minAppVersion 1.13.0

`display()` заменяется на `getSettingDefinitions()` плюс `getControlValue` /
`setControlValue`. Тогда настройки индексируются поиском настроек Obsidian.

Побочная выгода: «заметка для оверлея» получает `SettingFileControl` —
нормальный файловый пикер вместо ввода пути руками. Валидация через
`normalizePath` при этом больше не нужна на этом поле.

`minAppVersion` в манифесте поднимается до `1.13.0`, `versions.json` получает
`"0.5.0": "1.13.0"`. Старые записи не трогаем — пользователи на 1.4–1.12
останутся на 0.4.0, это штатное поведение каталога.

README и `docs/publishing.md`: обновить требование к версии Obsidian.

verify: настройки открываются и применяются вживую; строка настройки находится
через поиск в настройках Obsidian; выбор заметки работает пикером.

## Шаг 6. Релиз 0.5.0

`npm run bump 0.5.0`, коммит, тег `0.5.0`, пуш. Workflow собирает релиз с тремя
ассетами и аттестациями.

verify: `gh release view 0.5.0` — три ассета; запись в каталоге подтягивает
0.5.0; следующий автоотчёт ревью без каскада `no-unsafe-*`.

## Риски

| Риск | Что делаем |
|---|---|
| Переезд не убирает шум (их тулза вообще не ставит зависимости) | Раскладка всё равно станет канонической, а `npm run lint` в CI покажет правду по каждому релизу |
| `getSettingDefinitions` ведёт себя не так, как в типах | Проверяем руками в Obsidian до релиза; откат — вернуть `display()` и minAppVersion |
| Переезд ломает установку в Raincoat | Новый `install-local` перед релизом проверяем на живом vault |
| Swift-приложение перестаёт собираться | `swift build` и `swift test` из `macos/` в verify шага 1 |

## Что НЕ делаем

- Не меняем plugin id `tasks-for-focus-adhd`.
- Не трогаем логику таймера, парсер задач и их тесты.
- Не переписываем оверлей под декларативный API — он не про настройки.
