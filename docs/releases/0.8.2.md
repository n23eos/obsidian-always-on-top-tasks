## Added

- Safe quit workaround: one Quit request now closes Obsidian when the supported window configuration is open.
- Pending focus-session and task-timer operations are saved before closing. Active sessions, paused sessions and break timers retain their state after a full restart.
- If the final save fails, Obsidian stays open and displays an error so you can retry without losing the session.
- Quit guards clean up on plugin reload and cancel safely when another window or a conflicting shutdown handler is detected. Normal Obsidian save handlers remain in control; windows are never force-closed.

## Important limitation

**Safe quit currently works only with one vault window and one plugin focus window open.** It is enabled only on macOS with Obsidian 1.13.7 and Electron 39.8.3.

Additional vaults, settings popouts or other windows, unsupported versions, and later registered Quit handlers disable the workaround. These configurations keep Obsidian's normal shutdown behavior and may still require a second Quit request.

## Verified

- Full Obsidian process exit and restart from a single Quit request with both an active session and a paused session with a break. Session state, timers and the pinned focus window were restored.
- A simulated save failure kept the application and session open.
- Plugin reload cleanup and closing the focus window without quitting Obsidian.
- 187 automated tests, TypeScript checks, ESLint and the production build.
