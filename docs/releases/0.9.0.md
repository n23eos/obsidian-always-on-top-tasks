## Optional Focus Sessions

You can now turn **Focus sessions** on or off in the plugin settings. Turning them off removes the session panel and session filtering, so you can use the regular task overlay.

An unfinished session is kept on pause. Turn the feature back on and select **Resume focus** to continue. Your task selection and recorded time are preserved, including after reloading the plugin.

## Collapsible nested tasks

Use the arrow beside a parent task or list item to collapse or expand its children. Multiple nesting levels are supported, and the controls work with Enter and Space.

- Collapsing a list does not change your Markdown note.
- Hidden tasks still count toward progress and total time.
- A running timer remains accessible in the pinned header when its task is collapsed.
- Fold state survives task updates while the overlay view stays open. It resets when the view is closed.

## Fixes

- Folding a list with the emoji picker open no longer blocks later overlay updates.
- If saving a setting fails, the switch returns to its actual state and an error message is shown.
- Disabling a session preserves timers on unrelated tasks, including tasks in the same note.
- Retrying a failed session disable safely retries the pending timer save.
- Custom status emojis no longer reset fold state, and keyboard focus stays on the correct control when parent tasks share a name.

## Compatibility

Desktop only. Requires Obsidian 1.4.10 or later.

The existing safe-quit workaround retains its narrow scope: one vault window and one plugin overlay on the supported macOS, Obsidian 1.13.7 and Electron 39.8.3 configuration. Additional windows or unsupported configurations use Obsidian's normal quit behavior and may require a second Quit.
