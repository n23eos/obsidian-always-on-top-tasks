## Fixed

- Restored focus overlays are now recognized by the window controller after an Obsidian restart or plugin reload. Pinning and window controls work again, and toggling the overlay closes the existing window instead of creating a duplicate.
- Pending window-pinning attempts are canceled when the plugin unloads or the window closes, preventing stale retries from affecting another window.
- The pause/resume command now matches the Pause button: pausing starts a break when breaks are enabled, after the running task has been saved. A failed task save does not start a break.

## Verified

- Selected-task progress, undo/recheck and session completion in Obsidian.
- Active and paused focus sessions, task timers, break start times and the pinned overlay restored after complete process restarts on macOS.
- 149 automated tests, TypeScript checks, ESLint and the production build.

## Known Obsidian behavior

On Obsidian 1.13.7 with Electron 39.8.3 on macOS, quitting with a popout can close the windows while leaving the application process running. This also reproduces with an ordinary Obsidian popout. A second normal Quit request completed shutdown in testing. This release does not override Obsidian's shutdown handlers or force-close windows.
