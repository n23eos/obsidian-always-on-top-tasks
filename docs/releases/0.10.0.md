# 0.10.0 - Window sizing and quick privacy

This update addresses the three window-control requests in issues #1, #2 and #3.

## Improvements

- **Optional focus sessions.** Sessions are off by default. When enabled, setup has one clearly labeled task-count field, replacing the duplicate preset buttons and numeric input. Existing explicit opt-in preferences are retained.
- **A larger drag area.** Drag the overlay from any noninteractive part of its top block, including the space along both edges. Header buttons remain clickable.
- **Adjustable overlay height.** In Settings > Always-on-Top Tasks > Overlay window, turn off **Full height** and choose a height from 200 to 1200 pixels. The window stays within the available screen height. Full height remains the default, and free mode retains your manually chosen size.
- **Quickly hide private tasks.** Click the shield button or run **Hide or show overlay content**. The overlay replaces its note title, tasks and session details with a neutral placeholder. Click **Show content** or run the command again to return. Timers continue running, and hidden state survives plugin reload and workspace restoration.

## Fixes

- Saved window height is applied after settings load when the plugin reloads.
- Switching quickly from free mode to a docked position preserves the latest manual size.
- Pending renders, settings refreshes and note HTML cannot restore task content while the overlay is hidden.

## Hotkeys and scope

Assign a shortcut to **Hide or show overlay content** in Obsidian's **Settings > Hotkeys**. This is an Obsidian command, not a system-wide shortcut. This release implements the content-hiding option requested in issue #3; it does not add Windows Win+D integration. Hiding applies to the overlay, not other open notes or the main-window status bar.
