## Transparency and text size in one control

The subtle slider at the bottom of the overlay now has two modes:

- Click the eye icon to switch from window transparency to text size. The icon changes to a magnifying glass.
- Adjust text size from 11 to 18 px. Task rows adapt to the font size, and the preview updates as you move the slider.
- Click the magnifying glass to return to transparency. Both settings are saved independently.

The control has a thinner track and a smaller thumb for a quieter appearance.
