## Focus sessions

- Set a goal of 1-20 open tasks, use the 1/3/5 presets, or choose tasks individually.
- Work on one task at a time, with session progress and a collapsible next-task list.
- Pause and resume sessions, restore them after restarting Obsidian, and review the result when you finish.
- Progress follows the selected Markdown checkboxes. Undoing a completion updates the count without counting the same task twice.

## Breaks that survive a restart

- Active breaks now continue after Obsidian closes and reopens, including time spent with the app closed.
- Ending a break freezes its duration before saving. If a write fails, the pending break and its retry action survive a restart.
- Recovery recognizes an already recorded break and avoids adding its duration twice.

## Reliability and usability

- Safer timer recovery after failed writes, concurrent checkbox edits, and renamed notes or folders.
- Serialized settings updates prevent stale saves from overwriting newer state.
- Improved narrow-panel layout, keyboard focus restoration, and current-task emphasis.
- Better handling of CRLF notes and Markdown code examples during task selection.

## Verification

141 automated tests pass, together with TypeScript, ESLint and the production build. Browser checks cover session controls, restart recovery, failed saves and narrow panels. Two full Obsidian 1.13.7 process restarts also confirmed active-break restoration and recovery of a frozen pending break without double counting.

Desktop only. The minimum supported Obsidian version remains 1.4.10.

For manual installation, download `main.js`, `manifest.json` and `styles.css` from this release and place them in the plugin folder.
