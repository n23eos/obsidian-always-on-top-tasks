## What's new

- Add subtasks directly from the focus overlay. Hover over a task and click the plus button, then press Enter to save or Escape to cancel.
- Start a task timer from the same hover controls. The stop button remains visible while a timer is running.

## Fixes

- Align parent tasks and subtasks consistently, including lists indented with tabs.
- Keep task rows compact without reserving an empty line for hidden controls.
- Expand a collapsed parent when a new subtask is added, and preserve the draft if saving fails.
- Keep running timers attached to the correct task when a subtask is inserted above them.
- Reduce unnecessary work during rendering and remove the delay when collapsing a list.
