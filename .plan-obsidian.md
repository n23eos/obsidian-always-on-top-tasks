# Plan: Obsidian plugin "Tasks for Focus ADHD" (overlay-заметка поверх окон)

Папка: `obsidian-plugin/`. Plugin id: `tasks-for-focus-adhd`. Desktop only.
Отдельно от Swift-приложения SimpleFocus (у него свой `.plan.md`).

Ревизия 2: учтён главный урок SimpleFocus («неудобно нажимать») + разбор
банальных косяков. Изменения помечены ⚑.

## Goal

Выбранная заметка открывается в отдельном окне поверх всех приложений,
прижата к краю экрана, полупрозрачная, компактная. Текст заметки — как есть.
Строки-задачи (`- [ ] ...`) получают две всегда видимые кнопки: секундомер и
эмодзи-статус. Всё пишется обратно в сам .md-файл.

Verify целиком: `npm test` зелёный, `npm run build` без ошибок, плагин в vault,
команда-toggle открывает/закрывает overlay, секундомер пишет время в файл,
эмодзи проставляется, файл нормально читается в обычном Obsidian.

## UX-принципы (уроки SimpleFocus) ⚑

1. **Кнопки видны всегда, не по hover.** Hover-управление в SimpleFocus =
   промахи. Hit-target ≥ 28×28px.
2. **Один клик = одно действие, ноль печати в overlay.** Ввод текста — только
   в главном окне Obsidian. Overlay — читать и кликать.
3. **Минимум урона от кражи фокуса.** Electron не умеет nonactivating panel:
   клик по overlay активирует Obsidian. Смягчение: после каждого клика по
   кнопке — `win.blur()`, фокус возвращается системе. Задокументировать как
   ограничение платформы.
4. **Инструмент не врёт.** Секунды не теряются, забытый таймер не портит
   статистику молча.

## Формат данных — прямо в markdown

```
- [ ] 🔵 Фикс бага авторизации ⏱️ 0:01:23
- [x] ✅ Ответить в Slack ⏱️ 0:00:14
```

- Эмодзи-статус — сразу после чекбокса, из фиксированного набора.
- ⚑ Время — всегда `⏱️ Ч:ММ:СС` в хвосте строки. Секунды обязательны:
  короткие сессии (20–40 сек) не должны округляться в ноль.
- ⚑ Регулярки времени принимают `⏱` и `⏱️` (с/без U+FE0F) и старые `ЧЧ:ММ`.
- Никаких скрытых id и отдельных файлов состояния. Файл читаем глазами везде.
- data.json: только бегущий таймер `{ filePath, lineNo, lineText, startedAt }`.

Палитра: `⬜` не начато · `🔄` в работе · `⏸️` пауза · `🔜` отложено ·
`⛔` заблокирована ⚑ · `✅` готово · `❗` важно · `🔴 🟠 🟡 🟢 🔵 🟣` ·
`❌` снять метку.

## Ключевые решения

1. **Один бегущий таймер.** Старт нового останавливает предыдущий.
2. **Своя ItemView.** Заметка рендерится целиком; задачи — свои строки с кнопками.
3. **Запись через `vault.process(file, fn)`** — атомарно, без гонок.
4. **`@electron/remote` не бандлим** — рантайм-резолвер с try/catch
   (подход из obsidian-synaptic-hatch, MIT, атрибуция в README).
5. Ядро — чистые функции без импорта `obsidian`, покрыты vitest.
6. ⚑ **Адресация строки: `lineNo` + верификация по `lineText`.** При записи:
   строка на месте → пишем; нет → поиск по точному тексту; найдено 0 или ≥2 →
   Notice с накопленным временем (не теряем молча), таймер сбрасывается.
7. ⚑ **Ререндер не разрушает UI.** `vault.on('modify')` → debounce 300мс;
   пока открыта палитра — отложить; тик таймера — только DOM активной строки.
8. ⚑ **Палитра эмодзи — инлайн-полоска под строкой**, не floating-popover
   (в узком окне у края экрана popover вылезает за границы).
9. ⚑ **Связка действий:** чекбокс ✓ → эмодзи `✅` + стоп таймера этой строки.
   Снятие чекбокса эмодзи не трогает.
10. ⚑ **Забытый таймер:** сессия > 2ч коммитится, но с Notice
    «записано Ч:ММ:СС — проверь». Без блокирующих диалогов.
11. ⚑ **Toggle-команда + guard одного экземпляра.** Повторный вызов закрывает
    overlay, а не плодит второй.

## Assumptions (поправь, если не так)

- Vault для отладки: путь спрошу перед шагом 1; `npm run install-local` =
  симлинк в `.obsidian/plugins/`. Нет пути — соберу zip.
- Стек: TypeScript + esbuild (обвязка obsidian-sample-plugin), тесты vitest.
- Заметка выбирается в настройках + команда «открыть текущую заметку в overlay».
- Строка-задача: `^(\s*)([-*])\s\[( |x|X)\]\s`.
- Дефолт: правый край, 340px, высота экрана минус отступы, opacity 0.95.
- ⚑ YAML frontmatter в overlay не показывается (срезается до рендера).

## Out of scope

- Мобильный Obsidian. Синхронизация с SimpleFocus. Иерархия/drag&drop.
- Публикация в Community Plugins. Pomodoro/уведомления. Idle-детект.

## Risks

| Риск | Что делаем |
|---|---|
| `@electron/remote` не публичный API | try/catch везде; провал → Notice, view работает как обычная панель без always-on-top |
| Кража фокуса при клике (платформа) | blur после действия, ноль печати в overlay, README |
| `setFocusable(false)` нестабилен на macOS | выкл по умолчанию, «экспериментально» |
| Linux/Wayland игнорирует always-on-top | README |
| Гонка записи | только `vault.process`, никаких `vault.modify` |
| Правка/дубликаты строк при бегущем таймере | lineNo+lineText, при неоднозначности Notice с временем |
| Obsidian Tasks/Dataview рядом с нашим форматом | эмодзи и ⏱️ — обычный текст, чекбокс-синтаксис не ломаем; проверить руками на заметке с Tasks-плагином |
