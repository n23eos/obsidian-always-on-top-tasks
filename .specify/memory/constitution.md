# Always-on-Top Tasks: принципы проекта

Версия 1.0.0. Дата: 2026-09-19.

## Существующая структура

Obsidian desktop plugin на TypeScript; esbuild собирает main.js.
src/core содержит чистую Markdown-логику; TimerService управляет сессиями;
FocusOverlayView и styles.css отвечают за UI; Electron используется для окна.
macos содержит отдельное приложение SimpleFocus и не входит в эти изменения.

## Принципы

1. Задачи и накопленное время остаются обычным Markdown без скрытых ID.
2. Ошибка записи не должна незаметно уничтожать сессию. При неоднозначности
   сохранять данные для восстановления, не начислять время случайной строке.
3. Один таймер задачи; переходы состояния выполняются последовательно.
4. Кнопки видимы, доступны с клавиатуры, цвета используют переменные темы.
5. Сохранять существующий код и пользовательские настройки. Личные каталоги
   !notes игнорируются Git паттерном \!notes/ и не публикуются.

## Рабочий процесс

Новые изменения ведутся через specs/<feature>/spec.md, plan.md и tasks.md.
Состояние текущей разработки отражается в .plan-obsidian.md.
Использовать команды проекта: npm test, npm run check, npm run lint,
npm run build. Изменения таймера требуют регрессионных тестов;
визуальные изменения требуют осмотра UI и проверки затронутых сценариев.
Нативные Electron-функции нельзя считать проверенными браузерным стендом.
Публикация релиза выполняется только при соответствующем запросе пользователя.
