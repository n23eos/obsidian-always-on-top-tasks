# План реализации

1. TimerService: последовательная очередь, фиксированное окончание сессии,
   повтор сохранения, регрессионные тесты с mock Obsidian.
2. View: единый активный индекс, Lucide, закрепленная строка вне видимости,
   сохранение прокрутки при перерисовке и очистка обработчиков.
3. CSS: акценты, размеры кнопок, keyboard focus; статус-бар: постоянные узлы.
4. Проверки проекта и UI, установка трех файлов в Raincoat с сохранением data.json.

Основной агент владеет view, CSS, status bar и документацией; помощник владеет
TimerService, core/timer, settings и тестами сервиса. Независимое ревью после
интеграции. Базовые проверки до изменений: 67 тестов, check и lint проходят.
