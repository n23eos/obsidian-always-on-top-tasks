# Надежный таймер и спокойный интерфейс

Существующий плагин 0.7.0, desktop-only. Формат задач в Markdown сохраняется.

- Быстрые остановки и переключения выполняются последовательно.
- Неудачная запись оставляет остановленную сессию доступной для повтора,
  в том числе после перезапуска. Ее время больше не увеличивается.
- Одинаковые строки не отображаются обе как активные.
- Запуск и остановка используют Lucide; кнопки имеют видимый фокус.
- Накопленное время приглушено, активное выделено акцентом темы.
- Закрепленная задача появляется только когда ее строка прокручена выше шапки.
- Статус-бар обновляет текст времени без пересоздания SVG каждую секунду.

Не входят: новый режим одной задачи, локализация, полная инкрементальная
перерисовка, публикация релиза.
