# Сохранение времени после переименования

## Ожидаемое поведение

- Переименование заметки обновляет пути выбранной заметки, активного или ожидающего записи таймера и текущего перерыва.
- Переименование папки обновляет те же пути для всех вложенных заметок.
- Обновление работает при закрытом overlay и выполняется в общей очереди операций таймера.
- После переименования остановка записывает время в заметку по новому пути с прежним Markdown форматом.
- Если заметка перерыва отсутствует или запись не удалась, длительность фиксируется, пользователь получает уведомление, а повтор сохраняет ту же длительность.
- Переименование обновляет открытый overlay после того, как Obsidian уже изменил TFile.path.

## Границы

- Сохраняется один активный таймер и существующий формат строк времени.
- Перерыв, как и раньше, не переживает перезапуск Obsidian.
- Не меняются команды, настройки, формат data.json и пользовательский интерфейс за пределами состояния повторной записи.
- Установка в реальное хранилище, публикация, commit и push не выполняются.
