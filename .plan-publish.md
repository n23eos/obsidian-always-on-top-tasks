## Шаг 2. Правки по гайдлайнам Obsidian

1. **`onunload` не должен делать `leaf.detach()`** — прямой запрет гайдлайна
   (плагин не трогает раскладку пользователя). Оставляем только снятие
   always-on-top/opacity: окно превращается в обычный popout.
2. **Инлайн-стиль из JS**: `row.style.paddingLeft = …` → CSS-переменная
   `--tfa-indent` через `setProperty` + правило в `styles.css`.
3. **`normalizePath`** на пути заметки из настроек.
4. **Утечка таймаута**: `scheduleRender()` ставит `window.setTimeout`, но
   `onClose()` его не очищает — после закрытия оверлея коллбэк дёргает
   `render()` на отсоединённом DOM. Чистим в `onClose`.
5. **Типы `setState`**: `super.setState(state, result as never)` → импортировать
   `ViewStateResult` и убрать каст.
6. `getAbstractFileByPath` + `instanceof TFile` → `vault.getFileByPath`
   (актуальный API, три места, меньше кода).
7. Убрать локальный `sleep()` в `OverlayController` — Obsidian отдаёт глобальный.

verify: `npx tsc --noEmit` чисто, `npm run build` ок, `npm test` зелёный;
вручную: выключить плагин при открытом оверлее → окно перестаёт быть поверх
всех и не остаётся зависшим.

## Шаг 3. Защита от рассинхрона двух manifest.json

Корневой `manifest.json` и `obsidian-plugin/manifest.json` обязаны совпадать
байт в байт (каталог читает корневой, Obsidian ставит плагинный из релиза).
`npm run bump` синхронит только `version` — имя и описание я только что правил
руками в обоих файлах, в следующий раз забудется.

В `release.yml` расширить существующую проверку: сравнивать файлы целиком
(`diff manifest.json ../manifest.json`), а не только поле версии.

verify: намеренно рассинхронить локально → `diff` даёт ненулевой код возврата.
