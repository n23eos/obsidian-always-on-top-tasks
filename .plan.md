# План: 0.7.0 — настройки, интерфейс, стек

Статус: **выполнено и выпущено как 0.7.0** (2026-09-02) по прямому указанию
пользователя. Проверено вживую в Obsidian 1.12.7 через Obsidian CLI
(`obsidian vault=Raincoat plugin:reload`, `eval`, `dev:errors`).

Попутно найден и починен старый баг: класс `tfa-popout-body` на `body`
popout-окна никогда не держался — Obsidian переписывает классы body popout'ов,
синхронизируя с главным окном. Табы и view-header в overlay были видны всегда.
Теперь хром прячется CSS-селектором `body.is-popout-window:has(.tfa-overlay)`.

Порог `minAppVersion` поднят с 1.4.0 до 1.4.10: файловый саджест
(`AbstractInputSuggest`) появился в 1.4.10, линт это ловит.

## Что показало исследование

**Состояние.** 58 тестов, линт и сборка зелёные. Плагин в каталоге
(`tasks-for-focus-adhd`), статистики загрузок ещё нет. Issues на GitHub нет.

**Конкуренты.** Super Simple Time Tracker (42k загрузок) и Timekeep хранят
время в JSON-кодблоках, экспорт CSV/PDF, таймер в статус-баре. Synaptic Hatch
(14k) и Floating Notes — только «окно поверх всех», без таймера. Никто не
совмещает always-on-top + таймер на строке задачи + plain-text формат. Ниша
свободна, но у нас слабее: нет статус-бара, нет иконки в ribbon, нет группировки
настроек, окно жёстко прибито к краю, нельзя скрыть сделанное.

**Настройки.** Obsidian 1.13 публичен с 30 июля 2026 (у пользователя стоит
1.12.7 — потому декларативные настройки и откатили). Обе API совместимы: если
`getSettingDefinitions()` есть — 1.13 зовёт его, старые версии зовут
`display()`. Значит можно отдать **оба** из одного списка определений, а
`minAppVersion` оставить 1.4.0. Файловый пикер для старых версий —
`AbstractInputSuggest` (есть с 1.4.10).

**Стек.** TS + esbuild + vitest + typed eslint — канонично, менять нечего.
Не хватает официального `eslint-plugin-obsidianmd` — это ровно правила
ObsidianReviewBot (sentence case, no inline styles, prefer-instanceof…).
Obsidian CLI (`/usr/local/bin/obsidian`) умеет `plugin:reload`,
`dev:screenshot`, `dev:errors` — ускоряет ручную проверку.

**Скилы.** Единственный релевантный — `kepano/obsidian-skills/obsidian-cli`
(разработка и отладка плагинов через CLI). Установить в `~/.claude/skills`.
Скилов «obsidian plugin dev» в каталоге skillsmp нет; локальный
`desktop-commander:obsidian-vault` — про организацию vault, не подходит.

## Шаги

### A. Стек

1. **`eslint-plugin-obsidianmd`** в `eslint.config.mjs` (recommended), починить
   что найдёт. `npm run check` = `tsc --noEmit`, добавить в CI перед lint.
   → verify: `npm run lint`, `npm run check` чисто; CI-файл содержит оба шага.
2. **Скил obsidian-cli** → `~/.claude/skills/obsidian-cli/SKILL.md`;
   в README раздел Development: `obsidian plugin:reload id=tasks-for-focus-adhd`,
   `dev:screenshot`, `dev:errors`.
   → verify: файл скила на месте; README обновлён.

### B. Настройки (кастомизация)

3. **Одна модель — две API.** `src/settingDefinitions.ts`: список
   `SettingDefinitionItem` с группами-заголовками *Overlay window*, *Timer and
   breaks*, *Appearance*, *Advanced*. `SettingsTab.getSettingDefinitions()`
   отдаёт его (1.13+, поиск по настройкам); `display()` рисует тот же список
   через `Setting` (адаптер ~70 строк) для 1.4–1.12. Пикер заметки: `file`
   контрол / `addSearch` + `AbstractInputSuggest`. Кнопка «Reset to defaults».
   → verify: `npm run check`; в Obsidian 1.12.7 вкладка рисуется, изменения
   применяются к открытому overlay сразу.
4. **Новые настройки** (`settings.ts`, `DEFAULT_SETTINGS`):
   - `dockMode: "left" | "right" | "free"` (вместо `edge`; миграция старого
     `edge` при загрузке) + `freeBounds` — в режиме free окно помнит, где его
     оставили (сохраняем bounds при закрытии и по таймеру, если изменились).
   - `fontSize` 11–18 px → CSS-переменная `--tfa-font-size`.
   - `hideCompleted` — скрыть сделанные задачи.
   - `tasksOnly` — не рендерить обычный markdown между задачами.
   - `statusBarTimer` — бегущий таймер в статус-баре главного окна.
   - `showRibbonIcon` — иконка в ribbon для toggle overlay.
   - `statusEmojis` — своя палитра статусов (строка через пробел; пусто =
     стандартная). Парсер получает палитру параметром.
   - `breakReminderMinutes` виден только при `breaksEnabled`.
   → verify: тесты парсера с кастомной палитрой (RED→GREEN); каждая настройка
   меняет overlay без перезапуска.

### C. Интерфейс overlay

5. **Шапка окна** (`.tfa-header`, sticky над pinned-строкой): имя заметки,
   кнопки — скрыть/показать сделанные (глаз), pin/unpin always-on-top, закрыть.
   Прогресс-полоска done/total под шапкой. Пустое состояние подсказывает
   «+ task».
   → verify: кнопки работают; шапка не ломает sticky-строку бегущей задачи.
6. **Команды:** «Toggle always on top», «Stop the running timer»,
   «Toggle completed tasks in the overlay». Без дефолтных хоткеев.
   → verify: команды в палитре, работают при закрытом overlay без ошибок.
7. **Статус-бар** (`StatusBarTimer.ts`): «⏱ 0:12:40 · задача», клик = стоп.
   → verify: тикает синхронно с overlay; исчезает при стопе.

### D. Финал

8. README (Settings, Commands, Development), `docs/publishing.md` (порог версии:
   1.13 публичен, обе API). `npm run lint && npm run check && npm test &&
   npm run build`, `npm run install-local`, ручная проверка в Obsidian.
   Версию не бампаем и релиз не режем — это наружу, решает пользователь.

## Что НЕ делаем

- Не меняем формат строки задачи и id плагина.
- Не поднимаем `minAppVersion`.
- Не делаем экспорт/отчёты, drag-and-drop, idle-detection — отдельные фичи.
- Не коммитим и не тегируем без просьбы.

## Риски

| Риск | Что делаем |
|---|---|
| `getSettingDefinitions` в 1.12.7 нельзя проверить вживую | адаптер `display()` — основной путь; декларативный — по типам 1.13.1 и коду из истории |
| `eslint-plugin-obsidianmd` найдёт много | чиним настоящие, спорные правила отключаем явно с комментарием |
| free-режим: bounds с другого монитора | при открытии проверяем, что bounds пересекают какой-то display; иначе fallback к правому краю |
