# Plan: macOS floating "single task" focus anchor (Swift/SwiftUI, macOS 14+)

## Goal
Menu bar app + borderless always-on-top panel. Vertical "ladder" column:
completed tasks on top (gray, faded, max 5 visible, "+N" opens popup with rest),
current task at bottom (prominent), subtasks indented under it.
Verifiable: `swift build` + `swift test` green, .app launches, ⌘⇧L focuses input.

## Scope change (user, mid-task)
Was: single line. Now: column stack — completed (gray/faded, top) → current
(bottom) → subtasks under current. Tasks have subtasks. Max 5 completed shown,
overflow via popup on click.

## Scope change 2 (user)
- Several root tasks at once (task list), not one current.
- Hierarchy up to 5 levels deep (recursive subtasks).
- Color marker circle left of each task (green/red/blue/yellow/orange/purple,
  or none) — click opens palette popover, marks "this is what I'm doing".
- Root task complete → moves to gray completed stack; nested → strikethrough in place.
- Old saved state incompatible → starts fresh (no migration, per house rules).
Steps: 8. [x] rewrite core (tree ops, depth cap) + tests → `swift test` green (17 tests)
       9. [x] rewrite UI (recursive rows, color dot, add-task row) → build ok, smoke run ok

## Scope change 3 (user): polish pass
- BUG: abandoned empty edit/add fields stay stuck (focus lost → field never closes).
  Fix: on blur — commit non-empty, close empty; also on panel losing key.
- Drag & drop: any task draggable as a block (with subtree). Drop on row =
  insert before it (same parent → works across levels too). Drop on free space =
  move to end of root list. Guards: no drop into own subtree, depth cap 5 kept.
- Right-click context menu on rows (complete, subtask, color, delete) —
  discoverable alternative to hover icons.
Steps: 10. [x] core: movingTask(before:)/movingTaskToEnd + tests → swift test green (23)
       11. [x] UI: blur handling, onDrag/onDrop + highlight, context menu → build ok, app relaunched

## Assumptions (confirm if wrong)
- Swift Package + build script → .app bundle (no Xcode project).
- Hotkey ⌘⇧L via Carbon RegisterEventHotKey (no Accessibility permission).
- Click-through toggle in menu bar menu (panel unclickable while it's on).
- Click on completed task = restore it as current. Checkbox on current = complete.
- Persistence: Codable JSON in UserDefaults.
